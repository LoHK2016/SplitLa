# 07: 佔位成員、認領、退出

**What to build:** Member 可以加一個得個名嘅 Placeholder Member 並代佢入數；嗰個人之後經邀請連結加入嗰陣可以認領返自己個佔位。Member 就算有結餘都可以退出群組，退出後變返佔位成員，條數留低。

**Blocked by:** 03（活動、平均分開支、結餘）

**Status:** done

- [x] 加到佔位成員，可以做開支嘅畀錢人同有份嘅人
- [x] 經邀請連結加入嗰陣可以揀認領一個現有佔位成員，認領後帳目不變
- [x] 有結餘嘅成員退出到，退出後變成佔位成員，其他人仍然見到佢嘅結餘
- [x] Ledger 測試：認領同退出前後所有人結餘不變
- [x] 資料列權限測試：退出之後即時失去群組存取

## Comments

**2026-11-14（agent）：** 完成。

- 數據庫：成員可以加冇帳戶嘅成員行（佔位成員）；`join_group` 可以帶住要認領嘅佔位成員；`leave_group` 將自己嗰行同帳戶解除連結。成員行本身唔變，所以帳目唔變。
- App：群組頁選單有「加佔位成員」同「退出群組」；撳邀請連結嗰陣如果有佔位成員，會問你係咪其中一個。

要留意：

1. **主辦人退出之後仍然係嗰個活動嘅主辦人**，但佢已經冇帳戶，所以冇人改到活動預算同選定提案，直至佢認領返。未有轉交主辦人嘅功能。
2. **認領之後沿用佔位成員個名。**
3. 任何有邀請連結嘅人都可以認領任何佔位成員（spec 已經講明冇防認領錯嘅機制）。
