# 07: 佔位成員、認領、退出

**What to build:** Member 可以加一個得個名嘅 Placeholder Member 並代佢入數；嗰個人之後經邀請連結加入嗰陣可以認領返自己個佔位。Member 就算有結餘都可以退出群組，退出後變返佔位成員，條數留低。

**Blocked by:** 03（活動、平均分開支、結餘）

**Status:** ready-for-agent

- [ ] 加到佔位成員，可以做開支嘅畀錢人同有份嘅人
- [ ] 經邀請連結加入嗰陣可以揀認領一個現有佔位成員，認領後帳目不變
- [ ] 有結餘嘅成員退出到，退出後變成佔位成員，其他人仍然見到佢嘅結餘
- [ ] Ledger 測試：認領同退出前後所有人結餘不變
- [ ] 資料列權限測試：退出之後即時失去群組存取
