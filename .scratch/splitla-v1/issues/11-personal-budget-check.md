# 11: 個人預算同個人層面檢查

**What to build:** Member 私下定一個每月嘅 Personal Budget。每個提案顯示「如果去呢度，我今個月仲剩幾多」，超支就用紅色警告同顯示超支金額；另外有一頁睇到今個月 Committed Spend 由邊幾筆組成。個人預算只儲喺部機，其他成員同 server 都睇唔到。呢張係 SplitLa 嘅核心功能。

**Blocked by:** 10（選定提案同轉做開支）

**Status:** ready-for-agent

- [ ] 定到、改到、移除到每月個人預算，只儲喺部機
- [ ] 每個提案顯示個人層面嘅 What-if Check：剩餘金額，負數就係紅色超支警告
- [ ] Committed Spend 等於嗰個曆月開支入面我嘅份額，加我覆咗去嘅活動入面選定提案嘅份額；已轉做開支嘅提案唔重複計（Ledger 測試）
- [ ] 檢查一個提案嗰陣，同一活動現有選定提案嘅份額會被取代而唔係疊加（Ledger 測試）
- [ ] 跨月活動嘅開支各自計落自己日期嗰個月（Ledger 測試）
- [ ] Committed Spend 明細頁列出每一筆同所屬活動
- [ ] 冇定個人預算就唔顯示個人層面結果
- [ ] 有測試確認個人預算唔會出現喺任何發去 server 嘅請求
