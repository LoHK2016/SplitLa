# 09: 活動預算同活動層面檢查

**What to build:** Organiser 為活動定、改或者移除選填嘅 Activity Budget，全組睇到；每個提案顯示佢加埋活動已有開支之後會唔會超出活動預算同超幾多。

**Blocked by:** 08（出席狀態同提案）

**Status:** ready-for-agent

- [ ] 只有主辦人定到、改到、移除到活動預算，全組見到
- [ ] 每個提案顯示活動層面嘅 What-if Check：喺預算內或者超出幾多
- [ ] 計法係提案總額加活動已有開支，同一活動嘅其他提案唔計（Ledger 測試）
- [ ] 冇定活動預算就唔顯示活動層面結果
- [ ] 資料列權限測試：非主辦人改唔到活動預算
