# 04: 逐人金額同加一服務費

**What to build:** 記開支嗰陣，Member 可以改為逐人入實際金額，亦可以開「加一服務費」開關，照餐牌價入數都計到實際要畀嘅金額。

**Blocked by:** 03（活動、平均分開支、結餘）

**Status:** ready-for-agent

- [ ] 可以揀平均分或者逐人金額；逐人金額加埋唔等於總數就唔畀儲存並講明差幾多
- [ ] 開咗加一之後每人份額乘 1.1、四捨五入到仙，並調整到同總數吻合（Ledger 測試）
- [ ] 兩種分法配加一開關嘅組合都有 Ledger 測試
- [ ] 開支詳情顯示用咗邊種分法同有冇加一
