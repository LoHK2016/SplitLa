# 06: 建議轉帳同找數

**What to build:** Member 見到一組建議轉帳去找清全組嘅數，並且可以記錄一筆 Settlement 表示已經喺 App 以外畀咗錢，結餘即時更新。找數都可以改同刪，有改動記錄。

**Blocked by:** 03（活動、平均分開支、結餘）

**Status:** ready-for-agent

- [ ] 群組頁顯示建議轉帳（邊個畀邊個幾多）
- [ ] Ledger 測試：照建議轉帳之後全部人結餘歸零，次數唔多過人數減一
- [ ] 記到找數，雙方結餘更新，收錢嗰個見到記錄
- [ ] 找數可以改同刪，有改動記錄（如果 05 未做，就為找數建立同樣嘅記錄機制）
- [ ] App 冇任何真錢過數功能
