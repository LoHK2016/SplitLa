# 03: 活動、平均分開支、結餘

**What to build:** Member 喺群組開一個有名同日期嘅 Activity，記一筆 Expense（金額、邊個畀錢、邊啲人有份，平均分），然後見到每個成員喺成個群組嘅 Balance。呢張係分帳嘅第一條完整路徑。

**Blocked by:** 02（開群組同邀請加入）

**Status:** ready-for-agent

- [ ] 開到活動（名、日期），群組頁列出活動
- [ ] 記到一筆平均分嘅開支，可以唔屬於任何提案
- [ ] 除唔盡嗰陣餘數逐仙派畀頭幾個有份嘅成員，份額加埋等於總數（Ledger 測試）
- [ ] 群組頁顯示每個成員嘅結餘，跨晒所有活動；全組結餘加埋係零（Ledger 測試）
- [ ] 其他成員實時見到新開支同結餘變化
- [ ] 資料列權限測試覆蓋活動同開支
