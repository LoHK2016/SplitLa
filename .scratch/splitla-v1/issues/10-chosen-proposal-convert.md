# 10: 選定提案同轉做開支

**What to build:** Organiser 揀一個提案做 Chosen Proposal，可以改揀或者取消；活動完咗之後任何成員一撳將選定提案轉做開支，預先填好資料，只需要改實際金額同邊個畀錢。

**Blocked by:** 08（出席狀態同提案）

**Status:** done

- [x] 只有主辦人揀到、改揀到、取消到選定提案；一個活動最多一個
- [x] 活動冇日期就唔畀選定
- [x] 選定提案喺活動頁明顯標示，全組實時見到
- [x] 轉做開支嗰陣預填名稱、金額、有份嘅人（覆咗去嘅成員），儲存之後提案狀態變成已轉做開支
- [x] 提案三個狀態（開放、選定、已轉做開支）嘅轉換有測試
