# 13: 開 Apple Developer 帳戶同正式環境

**What to build:** 呢張要人親自做，agent 做唔到。開付費嘅 Apple Developer 帳戶，設定 App ID 同所需權限，產生推送通知金鑰，另外開一個正式嘅 Supabase 專案，等朋友可以經 TestFlight 裝到 App。做到覺得個 App 值得畀朋友用先做都得。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

- [ ] 有付費嘅 Apple Developer 帳戶
- [ ] App ID 開咗 Sign in with Apple、Push Notifications、iCloud（CloudKit）、App Groups
- [ ] 產生咗 APNs 金鑰並放入 Supabase 嘅密鑰設定
- [ ] 開咗正式 Supabase 專案，數據庫結構同資料列權限同本機一致
- [ ] App 上到 TestFlight，至少一個朋友裝到
