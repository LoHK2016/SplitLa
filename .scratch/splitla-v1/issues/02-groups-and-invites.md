# 02: 開群組同邀請加入

**What to build:** 用戶開一個 Group 並改名，產生邀請連結用分享面板傳出去；另一個用戶撳連結就成為 Member，雙方都見到成員列表。一個用戶可以屬於多個群組。

**Blocked by:** 01（專案骨架同 email 驗證碼登入）

**Status:** done

- [x] 開到群組、改到名，群組列表顯示我所屬嘅所有群組
- [x] 產生到邀請連結，另一個帳戶開連結之後加入群組
- [x] 成員列表實時更新
- [x] 資料列權限整合測試：非成員讀唔到亦寫唔到群組同成員資料

## Comments

**2026-11-14（agent）：** 完成。

- 數據庫：`groups` 同 `members` 兩個表連資料列權限。開群組同加入群組經數據庫函數做，所以冇邀請碼就加唔到自己入去。24 個權限測試全部通過（`npx supabase test db`）。
- App：群組列表、開新群組、群組頁（成員列表、改名、邀請朋友）、撳邀請連結之後嘅加入頁。
- 喺 iPhone 16 模擬器用三個帳戶行過：開群組 → 第二個帳戶加入，成員列表即時多咗一個人 → 第二個帳戶改名，標題即時更新 → 喺 App 改名 → 分享面板出到邀請連結 → 登出，未登入嗰陣開邀請連結，登入之後自動彈出加入頁 → 加入後見到三個成員。
- 冇喺畫面試過嘅：斷網同失效邀請連結嘅錯誤提示。

落手嗰陣定咗、冇同用戶確認過嘅決定：

1. **邀請連結用自訂 scheme（`splitla://join?token=…`）。** 一般 https 連結要撳完直接開 App，需要付費 Apple Developer 帳戶（排喺 13 後面）。代價係 WhatsApp 唔會將 `splitla://` 變成可以撳嘅連結，朋友要複製貼上先開到。有帳戶之後應該轉做 https 連結。
2. **每個群組得一條長期有效嘅邀請連結**，所有成員都見到同一條。未有作廢或者重新產生連結嘅功能。
3. **成員嘅名係逐個群組定嘅**，開群組同加入嗰陣問，預設用電郵 @ 前面嗰段。
4. **任何成員都可以改群組名。**
