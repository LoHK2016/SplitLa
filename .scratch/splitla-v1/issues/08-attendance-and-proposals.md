# 08: 出席狀態同提案

**What to build:** Member 對每個 Activity 標記 Attendance（去、唔去、未覆），見到邊個去邊個未覆；任何成員可以開 Proposal，入「每人」或者「總數」，一個活動可以有多個提案並排睇，每個提案顯示我嘅 Share。

**Blocked by:** 03（活動、平均分開支、結餘）

**Status:** ready-for-agent

- [ ] 每個成員標記同改到自己嘅出席狀態，活動頁顯示各人狀態
- [ ] 如果 07 已做，可以代佔位成員標記出席狀態
- [ ] 開到每人模式同總數模式嘅提案，一個活動可以有多個
- [ ] 每個提案顯示我嘅份額；未覆或者唔去嘅人以「假設我去」計
- [ ] Ledger 測試：兩種模式嘅換算、出席人數變動之後份額重算、餘數處理
- [ ] 其他成員實時見到新提案同出席變化
